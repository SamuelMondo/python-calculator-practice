# Python Calculator — practice project

This is a learning project, not an Alignerr assessment submission.

## Run it

Install Python 3, open a terminal in this folder, then run:

```bash
python calculator.py
```

On Windows, `py calculator.py` may work instead.

## Run tests

```bash
python -m unittest discover -v
```

## Practice ideas

Read the `calculate` function and try changing the welcome message. Then explore how the tests verify arithmetic and division-by-zero handling.
